# MySR

MySR — Symbolic Regression (符号回归) 工具库，面向核物理实验数据分析。

基于 PySR (Python) + SymbolicRegression.jl (Julia) 技术栈，处于开发阶段。

## 目录

- `Features/` — 特征工程脚本
- `Loss Function/` — 损失函数实验
- `Operators_and_Constraints/` — 算子与约束
- `Reference/` — 架构与设计文档（architecture / api / julia bridge / export system / search loop）

## 环境

- Python 3.11 (conda env: `env_nusr`)
- Julia 1.12
- 包管理: poetry

## 状态

Development in progress.

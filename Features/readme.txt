=====================
这里记录一下Feature中各个版本的py文件的意义
=====================

1. 1.1：gpt给的常见的核结构和核反应的feature集合，可以作为一个module导入，然后使用，生成为pandas的dataframe表格
2. 1.2： 直接将1.1中的feature提取出来，制作为函数的形式，之后可以直接使用，不必像之前那样先生成表格，之后再提取对应的内容。但是这里只有核结构的常见参数，核反应的没做，因为核反应的参数太多了，更别说可能的feature了。不好统一制作使用，这里就先分给出了核结构的feature function形式。

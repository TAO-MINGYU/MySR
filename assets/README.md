# MySR page assets

- `mysr-mark.svg` and `mysr-lockup.svg` are the MySR Python frontend identity assets.
- `mysr-icon-data.svg`, `mysr-icon-equation.svg`, and `mysr-icon-pipeline.svg` are the reusable workflow icons shown in the README.
- `social-preview.png` is a 1280×640 GitHub social-preview candidate.
- `social-preview.svg` is the editable vector source for that preview.
- `result-preview.png` and `result-preview.svg` are illustrative README result views.

The MySR visual system uses cobalt (`#1769E0`) for the Python-facing workflow,
amber (`#F4A340`) for data and insight accents, and deep navy for readable text.
All visible copy in these assets is English. The social-preview files are
presentation assets; they do not contain benchmark results or runtime-generated
data.
